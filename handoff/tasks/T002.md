# T002 — Phase-split residual Conv1D curve encoder (new family, for ZN-E008)

Why: prepare.preprocess_cycle always builds each cycle as [charge 150 pts | discharge 150 pts] (charge-first and
discharge-first ZN-coin cells are re-ordered). The ZN-E005 curve encoder slides one Conv1D stack over all 300 points,
so kernels straddle the charge/discharge boundary at index 150 and both phases share every filter. Zn-ion charge
(Zn plating / cathode deintercalation) and discharge have different shapes; long-life cells are the main error.

Add class `PhaseSplitResConvMaskedSummary(ResidualConvMaskedSummary)` in `train.py`:
- `encode_curve_features(curves)`: curves [B,100,3,300] -> charge = curves[..., :150], discharge = curves[..., 150:].
  Each phase has its OWN stem (Conv1d 3->16 k7 s2 p3, ReLU, Conv1d 16->32 k5 s2 p2, ReLU, Conv1d 32->d_model//2 k3 s2 p1, ReLU),
  its own `residual_layers` ResidualCurveBlock(d_model//2) and AdaptiveAvgPool1d(1). Concat -> [B,100,d_model].
  GroupNorm groups in the half-width blocks must divide d_model//2 (8 groups for 32 ch is fine).
- Everything after the curve features (masked mean/last/last-first summary, inter_summary, inter_mlp (0 blocks), head)
  is inherited unchanged from ResidualConvMaskedSummary, so forward/summary code must be reused, not copied.
- `diagnostic_modules()`: charge_stem, discharge_stem, charge_residual, discharge_residual, inter_summary,
  (inter_mlp if non-empty), head.
- `build_model`: variant "phase_split_resconv_masked_summary" with d_model, residual_layers, d_ff, mlp_layers,
  summary_mode, dropout.
Tests (tracked, `git add -f tests/test_phase_split_encoder.py`): padding invariance (noise in mask==0 cycles does not
change output), phase isolation (changing discharge points of a cycle leaves the charge-branch features of that cycle
unchanged), finite forward [2,100,3,300], param count printed.

"mlp_layers":0,"summary_mode":"mean_last_delta","dropout":0.1}
